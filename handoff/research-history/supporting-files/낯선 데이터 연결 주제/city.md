# 도시 상업 건물 인프라의 의외 연결 8개

아래 메시지는 모두 검증할 가설이며 분석 결과가 아니다. 데이터셋 소개·필드·파일 존재를 온라인에서 확인했다. 실제 API 키 발급, 전체 파일 다운로드, 결측률 실측은 수행하지 않았다. 우선순위는 1·2·3·4, 나머지는 예비다. 조사일 2026-11-02.

## 1. 동물병원은 1층인데 사람 병원은 왜 위층일까

### Takeaway
사람과 반려동물이 치료받는 장소의 '높이'를 비교한다. 두 종류 병원 주소에서 층을 추출하는 수집 방법이 독특하며, 도시의 수직 접근성이라는 이야기를 만들 수 있다.

### Cited Findings
- 데이터 A: 서울시 동물병원 인허가 정보. 영업상태, 도로명주소, 사업장명, 좌표 등. CSV/서울 OpenAPI, API 키 필요. 현재 영업 중인 곳만 선택한다. 공식 설명에 좌표계 EPSG:5174와 3일 전 자료 제공을 명시한다. [공식 데이터](https://data.seoul.go.kr/dataList/OA-16007/S/1/datasetView.do)
- 데이터 B: 건강보험심사평가원 병원정보서비스. 기관명, 주소, 종별 등 신고기반 기관정보. API 키 필요. 의원급 일반·치과·한의원을 각각 분리하면 비교가 선명하다. [공식 API](https://www.data.go.kr/data/15001698/openapi.do)
- 동물병원 원천주소에는 '1층,2층,지하1층'처럼 실제 층 표기가 포함된 사례가 확인된다. [원천을 활용한 서울 디렉터리](https://mypetchu.com/vet-finder/)

### Inferences
- 가설 메시지: 같은 동네라도 동물병원과 사람 의원은 다른 높이에 입지할 수 있다. 병원을 찾는 거리는 지도 위 수평거리만으로 설명되지 않는다.
- 결합: 같은 수집일 현재 서울 / 행정동 또는 상권 500m 내 비교. 개별주소의 층수 분포를 병원 종류별로 비교한다.
- 방법: 정규식으로 '지하·B·층·호' 추출, 여러 층 점유는 별도 처리. 표본을 지도/병원 공식 웹페이지로 확인한다.
- 시각화: 건물 단면 실루엣에 병원 종류별 층 분포를 쌓기. 수집 난이도 중.

### Gaps
- 층 누락을 1층으로 간주하면 안 된다. '101호'를 무조건 1층으로 환산하면 안 된다. 병원 주소에 층 표기가 없는 비율은 파일 확보 후 측정 필요.
- 위층에 있다고 접근성이 낮다고 단정할 수 없다. 엘리베이터 여부를 보려면 건축HUB 승강기 필드 추가가 필요하다. 임대료, 기관 규모, 진료과, 상권 차이 통제 필요.

## 2. 영어 상호는 정말 외국인이 많은 동네에 많을까

### Takeaway
사업장 이름 속 로마자 비율을 외국인 거주·체류 밀도와 비교한다. 외국인을 위한 언어인지, 내국인을 위한 유행의 문법인지 묻는다.

### Cited Findings
- 데이터 A: 소상공인시장진흥공단 상가(상권)정보. 상호명·업종·행정동·주소·위경도 등. API 키 필요, 파일데이터 경로도 제공된다. [공식 API](https://www.data.go.kr/data/15012005/openapi.do), [파일](https://www.data.go.kr/data/15083033/fileData.do)
- 데이터 B: 행정동 단위 서울 생활인구(장기체류 외국인). 월별 ZIP 파일 2026년 7월까지 확인. 기존 생산은 2026년 7월31일 이후 종료라고 원문에 명시되어 있다. [공식 데이터](https://data.seoul.go.kr/dataList/OA-14992/S/1/datasetView.do)
- 현재 시점에는 새 250m 격자 장기외국인 생활인구로 전환하거나, 위 과거 파일과 같은 시점의 상가 파일을 사용해야 한다. [전환 공지](https://data.seoul.go.kr/together/notice/boardView.do?seq=721010a1522630fbf7a78d381a8326ee), [현재 생활인구 다운로드 안내](https://data.seoul.go.kr/dataVisual/seoul/seoulLivingPopulation.do)

### Inferences
- 가설 메시지: 영어 상호가 많은 동네가 반드시 외국인이 많은 동네는 아닐 수 있다. 상업 언어는 이주민의 생활보다 소비 유행을 더 반영할 수 있다.
- 결합: 2026년 6월 상가 파일과 2026년 6월 외국인 생활인구 등 동일분기 행정동 단면. 최신 자료를 쓰면 점포 좌표를 250m 격자에 할당한다.
- 방법: 로마자 포함 비율, 순수영문 비율, 외국어 한글음차를 별도로 정의. 프랜차이즈 제거/포함 비교. 카페업만 보거나 업종별로 층화하면 좋다.
- 시각화: 외국인밀도×영문상호비율 사분면 지도와 예외동네 간판 사례. 수집 난이도 중.

### Gaps
- 등록상호는 실제 간판과 다르다. 최종 제목에서 간판이라고 단정하지 않는다. 실제 간판을 보려면 선정표본 거리뷰/현장사진 수작업 라벨링 필요.
- 영어가 아닌 로마자 상호도 있으므로 '영어' 제목은 의문형으로 두고 지표는 로마자 상호 비율로 정확히 표기한다. 관광객, 소득, 업종, 프랜차이즈 효과 통제.

## 3. 학원가에는 어린이 변기가 있을까

### Takeaway
아이들이 많이 모이는 장소와 아이들의 몸에 맞는 공공시설이 같은 곳에 있는지 묻는다. 단순 어린이 인구 대신 학원의 정원과 위치로 아동의 실제 활동 장소를 살펴보는 점이 좋다.

### Cited Findings
- 데이터 A: 서울시 학원 교습소정보. 학원명, 등록상태, 정원, 분야·계열·과정 등 제공. 원천 NEIS, Sheet/OpenAPI. 2026-10-27 갱신 확인. [공식 데이터](https://data.seoul.go.kr/dataList/OA-20528/S/1/datasetView.do)
- 데이터 B: 전국공중화장실표준데이터. 주소·위경도·남녀 어린이용 위생시설 수·개방시간 등. 다운로드 Excel/표준데이터 API. [공식 데이터](https://www.data.go.kr/data/15012892/standard.do), [공공 교육데이터 메타 설명](https://data.edmgr.kr/dataView.do?id=www-data-go-kr-data-standard-15012892)

### Inferences
- 가설 메시지: 학원과 학습 인프라가 몰린 동네라도 어린이를 위한 생활 인프라는 부족할 수 있다. 아이를 모으는 도시와 아이가 머무르기 편한 도시는 다를 수 있다.
- 결합: 동시점 서울 현황 / 학원 주소 기준 반경 300~500m의 어린이 변기 수. 초등대상 과정을 분리하고 정원을 수요 대리지표로 쓴다.
- 시각화: 학원 정원 원 크기와 어린이 화장실 접근권의 빈틈 지도. 수집 난이도 중.

### Gaps
- 학원 정원은 실제 등록 학생 수가 아니다. 학원 내부 화장실은 공중화장실 데이터에 거의 포착되지 않으므로 총 화장실 부족으로 결론내리면 안 된다. 질문은 '학원가 주변 공공 어린이 화장실'로 한정한다.
- 학원 주소 및 과정 필드 활용은 실제 응답의 결측률 확인 필요. 어린이 변기 숫자 누락도 미설치와 구분한다.

## 4. 밤에는 사람보다 화장실이 먼저 퇴근할까

### Takeaway
고정 시설 지도를 시간에 따라 열리고 닫히는 지도로 바꾸고, 그 시간에도 남아 있는 생활인구와 비교한다.

### Cited Findings
- 데이터 A: 전국공중화장실표준데이터, 개방시간·개방시간상세와 좌표. [공식 데이터](https://www.data.go.kr/data/15012892/standard.do)
- 데이터 B: 서울 생활인구. 특정 지역·시간의 통신기반 추정인구이며 시간단위, 250m 격자 파일을 제공한다. [공식 다운로드/설명](https://data.seoul.go.kr/dataVisual/seoul/seoulLivingPopulation.do)

### Inferences
- 가설 메시지: 도시의 밤은 조명이나 매장 영업만으로 유지되지 않는다. 사람들이 남아 있는 시간에 기초 생활시설이 먼저 닫히는 사각지대가 존재할 수 있다.
- 결합: 최신 동일월 생활인구 22~02시 × 비슷한 기준일의 화장실 현황. 시간대마다 열린 화장실/변기 수와 생활인구 1만명당 공급을 계산.
- 시각화: 밤이 깊어질수록 화장실 점은 사라지고 인구 빛은 남는 애니메이션 지도. 난이도 중.

### Gaps
- 생활인구에는 실내 체류자도 포함되어 길 위의 화장실 수요와 같지 않다. 공중/개방화장실에 한정하며 상업시설 손님용 화장실을 포함한 총 공급으로 해석하지 않는다.
- 개방시간 문자열 표준화와 실제 운영 표본 확인 필요. 현재 화장실 목록으로 과거 인구를 분석하면 설치·폐쇄 이력이 반영되지 않는다.

## 5. 커피를 살 곳과 컵을 버릴 곳은 함께 늘었을까

### Takeaway
카페와 가로휴지통이라는 판매·처리 인프라를 겹쳐 도시의 일회용컵 처리 공백을 찾는다. 연관성 자체는 비교적 직관적이라 예비 후보.

### Cited Findings
- 데이터 A: 소상공인시장진흥공단 상가정보, 카페업종·주소·위경도. [파일데이터](https://www.data.go.kr/data/15083033/fileData.do)
- 데이터 B: 서울 영등포구 가로휴지통. 주소·상세위치·위경도·설치장소유형·수거쓰레기종류·쓰레기통형태 제공. 2024-08-28 CSV 확인. [공식 데이터](https://data.seoul.go.kr/dataList/OA-22383/F/1/datasetView.do)

### Inferences
- 가설 메시지: 소비를 만드는 점포는 골목 안까지 들어오지만 소비 후 처리를 돕는 공공시설은 큰길에 머무를 수 있다.
- 결합: 영등포구 2024년 3분기 상가 파일 × 2024-08-28 휴지통 현황. 카페 기준 200m/400m 내 휴지통 유무, 컵 분리수거 가능 유형 구분.
- 시각화: 카페에서 가장 가까운 쓰레기통까지 거리선, 여의도/문래 등 소지역 대조. 난이도 하~중.

### Gaps
- 모든 카페가 테이크아웃 위주는 아니며 카페 수는 일회용컵 배출량이 아니다. 카페 매출·유동인구·도로 구조 통제. 타 자치구는 별도 현황을 확보해야 한다.

## 6. 전기차를 가르는 것은 차의 나이보다 집의 나이일까

### Takeaway
충전인프라를 아파트 준공연도와 결합해 전기차 접근성의 주거 격차를 살펴본다. 정책과 직접 연관성이 있어 새로움보다 실행가능성이 강한 예비 후보.

### Cited Findings
- 데이터 A: 국토교통부 건축HUB 건축물대장정보 서비스. 표제부의 사용승인일·세대수·용도·주소 등을 활용. API 키 필요. [공식 API](https://www.data.go.kr/data/15134735/openapi.do)
- 데이터 B: 전국전기차충전소표준데이터/한국환경공단 충전소 API. 주소·좌표·충전용량·이용시간·이용자 제한·주차요금 관련 필드 제공. [공식 표준데이터](https://www.data.go.kr/data/15013115/standard.do), [환경공단 API](https://www.data.go.kr/data/15076352/openapi.do)

### Inferences
- 가설 메시지: 같은 가격의 전기차를 사도 주거 건물의 세대에 따라 충전 일상의 비용이 달라질 수 있다.
- 결합: 동시점 서울 아파트 건물/단지 × 같은 주소에 설치된 충전기. 준공연대별 세대당 충전기 수와 외부충전소까지 거리 비교.
- 시각화: 준공연도 순으로 아파트 단면/충전기 비율 정렬. 난이도 중.

### Gaps
- 충전소 API에 잡히지 않는 비공개 개인 충전기가 있을 수 있다. 사용자 제한도 구분한다. 충전기 수와 충전 가능량은 다르므로 급속/완속 분리. 단지 중복주소·여러 동의 세대수 중복 합산 주의.

## 7. 막차가 끊기면 동네의 심장충격기도 닫힐까

### Takeaway
교통시설에 의존하는 공공안전 인프라의 시간 제약을 드러낸다. 막차와 역사 폐쇄는 시간적으로 가까워 의외성보다 메시지 전달력이 강한 예비 후보.

### Cited Findings
- 데이터 A: 서울교통공사 역별 자동심장충격기 설치현황. 2025-03-10 기준 CSV가 확인된다. 역사 내부에 비치된 장비의 역·대수·위치를 제공. [공식 데이터](https://data.seoul.go.kr/dataList/OA-22495/L/1/datasetView.do)
- 데이터 B: 서울 도시철도 열차운행시각표. 역코드·역명·방향·도착/출발시간·평일/토요일/휴일 구분. [공식 파일](https://www.data.go.kr/data/15098251/fileData.do), [서울 2025-09-30 CSV](https://data.seoul.go.kr/dataList/OA-22522/F/1/datasetView.do)

### Inferences
- 가설 메시지: 지도에 찍힌 AED가 하루 종일 접근 가능한 것은 아닐 수 있다. 교통망이 문을 닫는 시간이 안전망의 일부가 사라지는 시간이 될 수 있다.
- 결합: 공통 역명·호선. 동일 2025년 기준으로 시작하고 막차~첫차 구간의 잠재 접근제한 시간을 산정. '접근제한 가능성'만 표시하고 역사 실제 개폐시간을 표본 확인한다.
- 시각화: 노선도의 AED 불빛이 막차 이후 꺼지는 지도. 난이도 중.

### Gaps
- 막차시각은 AED 이용가능시각과 같지 않다. 역무원이 남아 있거나 외부 접근이 가능할 수 있다. 열차시각표만으로 밤에 AED를 쓸 수 없다고 주장하면 안 된다. 역 문 개폐시각 수집이 필요하다.
- 해당 데이터만으로 동네 전체 AED 공백을 판단할 수 없다. 주변 다른 AED를 비교하려면 추가 자료 필요.

## 8. 택배보관함은 엘리베이터 없는 동네를 찾아갔을까

### Takeaway
안심택배함을 1인가구 대신 주택의 수직 이동 부담과 연결한다. 설치 목적과 실제 공간적 효과를 다른 각도에서 살펴볼 수 있는 예비 후보.

### Cited Findings
- 데이터 A: 서울시 안심택배함 설치 현황 및 구간 점유율. 2026년 6월 기준 XLSX를 2026-07-24 공개. 주소·운영상태·개소/연도별 실적을 제공한다고 설명. [공식 데이터](https://data.seoul.go.kr/dataList/OA-23034/F/1/datasetView.do)
- 데이터 B: 국토교통부 건축HUB 건축물대장. 승용승강기 수·지상층수·가구수·세대수·주소 필드를 활용한다. API 키 필요. [공식 API](https://www.data.go.kr/data/15134735/openapi.do), [필드명 참고: 오픈소스 API 래퍼 문서](https://github.com/WooilJeong/PublicDataReader/blob/main/assets/docs/portal/BuildingLedger.md)

### Inferences
- 가설 메시지: 문 앞까지 오르는 노동이 큰 동네일수록 공동 수령시설이 유용할 수 있다. 보관함의 가치는 범죄예방뿐 아니라 도시의 마지막 계단에서 볼 수 있다.
- 결합: 2026년 6월에 가까운 건축물 현황 × 운영 중 택배함. 택배함 반경 300~500m에서 3층 이상/승강기 0 주택 비율, 가구당 함 수 또는 최근접거리.
- 시각화: 택배함 접근권 원에 계단 많은 주거건물을 표시. 난이도 중~상.

### Gaps
- 실제 배송노동 강도, 택배 물량, 택배기사가 보관함을 선호하는지는 두 데이터로 알 수 없다. 가설의 공간 배치까지만 검증한다.
- API 건축물대장은 현재 현황이어서 2026년 6월 스냅샷과 몇 개월 시점 차이가 생길 수 있다. 승강기 0과 결측 구분 필요.
- 택배함 원문 라이선스는 공공누리 4유형(출처표시·비상업·변경금지)으로 표기되어 있다. 최종 산출물의 데이터 재배포/변경 가능 범위는 제공기관에 확인 필요. 따라서 우선 실행 주제로는 1~4가 더 적합하다.

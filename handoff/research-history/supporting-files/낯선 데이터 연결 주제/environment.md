# 환경과 식생활의 낯선 연결

## 어떤 두 자료를 실제로 연결할 수 있는가

### Takeaway
아래 8개는 분석 결과가 아니라 연구 가설이다. 1~6은 한국을 대상으로 할 수 있고, 7~8은 해외 사례다. 가장 권하는 것은 2, 3, 5, 7이다. 4와 6은 같은 가격 데이터원을 재사용하므로 최종 20개에서는 둘 중 하나를 택하는 편이 다양하다. 실제 API 키를 발급받아 자료를 내려받은 단계는 아니다. 공식 데이터셋·제공 문서의 존재와 제공 항목을 확인했으며, 각 항목의 표본 충분성은 후속 수집으로 검증해야 한다.

### Cited Findings

#### 1. 꽃은 피었는데 축제는 아직일까?
- 데이터 A: 기상청 계절관측. 관측소·연도·식물종별 개화 날짜를 조회하는 공식 화면이 존재한다. 파일 추출/화면 수집을 활용한다. [기상청 계절관측](https://data.kma.go.kr/data/seasonObs/seasonObsDataList.do?pgmNo=648).
- 데이터 B: 전국문화축제표준데이터. 축제명·시작/종료일·좌표·주소·기준일을 CSV/XLS/API로 제공한다. 분기 갱신이며 최신 목록이지 과거 전 기간의 완전한 축제 이력은 아니다. [전국문화축제표준데이터](https://www.data.go.kr/data/15013104/standard.do).
- 연결: 우선 2026년 벚꽃축제별 가장 가까운 관측소를 매칭하고, 개화일에서 축제 첫날까지 일수를 비교한다. 다년 분석은 지자체 과거 공고/포스터를 추가 수집해야 한다.
- 가설: 지역축제 일정은 꽃의 생물학적 달력보다 주말·행정 일정에 묶여 있어 지역마다 꽃과 축제의 시차가 다를 수 있다.
- 시각화: 꽃 개화와 축제기간을 한 줄에 놓는 지역별 타임라인, 개화-축제 시차 지도.
- 난도: 중. 한계: 관측소의 표준목과 실제 축제장 식생·고도·만개일이 다르다. 개화일을 만개일로 쓰지 않는다.

#### 2. 나방은 도시의 불빛을 따라 밤을 새울까?
- 데이터 A: NASA Black Marble 야간조명. 약 500m 격자, 일/월/연 야간복사량 제품을 제공한다. 공간 파일을 내려받아 관측점에 붙인다. [NASA 야간조명 제품](https://ladsweb.modaps.eosdis.nasa.gov/missions-and-measurements/science-domain/nighttime-lights). NASA 원자료는 Earthdata 계정·다운로드 절차가 필요하다.
- 데이터 B: iNaturalist 생물관찰. 공식 API와 관찰 검색/내보내기 경로가 있다. 한국의 나방 관찰기록에서 종·좌표·관찰 날짜/시각이 기재된 기록만 추린다. [공식 API 안내](https://www.inaturalist.org/pages/api+reference), [지원 API](https://api.inaturalist.org).
- 연결: 2021~2025년 한국, 같은 종·월에 대해 조명 밝기 구간별 밤중 관찰시간 분포와 관찰 종 구성을 비교한다.
- 가설: 밤의 밝기는 곤충이 발견되는 시간과 종 구성에 연결되어, 도시조명 지도가 곤충의 밤 지도로 다시 읽힐 수 있다.
- 시각화: 밝기 구간별 24시간 원형 차트, 빛 격자 위 관찰점 지도.
- 난도: 상. 핵심 한계: 이 데이터는 행동을 연속 측정한 것이 아니라 사람이 사진을 찍은 시각이다. 관찰자 야간활동, 유인등 채집, 동일 관찰자 반복기록을 통제해야 하며 결과를 '나방의 수면시간'이라 부르면 안 된다. 실제 한국 표본의 시각기재율 미확인.

#### 3. 외래식물도 기차를 탈까?
- 데이터 A: GBIF 생물 출현기록. 좌표와 관찰일이 있는 한국의 특정 외래식물 기록을 검색/API/CSV로 확보할 수 있다. 대량 다운로드에는 무료 계정이 필요하다. [GBIF 출현 API](https://techdocs.gbif.org/en/openapi/v1/occurrence).
- 데이터 B: OpenStreetMap 철도 선로·역. Overpass API로 한국 지역의 railway 태그가 붙은 선/점을 가져온다. [Overpass 공식 공동체 문서](https://wiki.openstreetmap.org/wiki/Overpass_API).
- 연결: 2020~2025년 관찰 좌표와 철도·화물역까지의 거리, 100/500/1000m 완충구역별 출현 비중을 계산한다. 전국 또는 한 광역권.
- 가설: 외래식물의 분포가 기후뿐 아니라 화물·토사·인간 이동의 통로인 철도망을 따라 나타나는지 시험한다.
- 시각화: 철도노선을 덩굴처럼 따라가는 식물 출현 지도, 거리별 외래종/비외래종 관찰 비중.
- 난도: 중상. 한계: 역 주변은 사람이 많아 기록 자체가 많다. 외래종 관찰 건수만 세면 안 되며, 동일 지역의 전체 식물 관찰·교란지 면적·도로망과 비교해야 한다. GBIF가 자체적으로 모든 종의 '외래 여부'를 보증하는 것은 아니므로 국내 지정 목록으로 종을 먼저 선정한다. 현재 선로와 과거 관찰일의 차이도 검토한다.

#### 4. 생선값에는 29.5일짜리 리듬이 있을까?
- 데이터 A: 한국천문연구원 음양력 정보. 양력-음력 날짜·윤달 등을 API로 제공한다. [공식 데이터셋](https://www.data.go.kr/data/15012679/openapi.do). API 키 필요. 음력 날짜는 조석·야간 밝기와 관련한 주기 지표로 쓰되 실제 조위나 정밀 달 위상 자체가 아니다.
- 데이터 B: KAMIS 일별 품목별 도·소매가격. 품목·품종·등급·지역별 일별 가격 API가 있고 기간 지정 신 API는 요청당 최대 1년이다. [KAMIS 공식 API 안내](https://www.kamis.or.kr/customer/reference/openapi_list.do). 키 발급 필요.
- 연결: 가격조사 품목 중 생물/신선 수산물과 냉동 수산물을 골라 2021~2025년 일별 가격을 음력일에 맞춰 겹친다. 품목·등급·규격을 고정한다.
- 가설: 어획이 조업 여건의 영향을 받는 생물 수산물 가격에 주기가 보이고 냉동품에는 약하다면, 달의 달력이 식탁가격에 남는지 보여줄 수 있다.
- 시각화: 음력 1~30일 원형 가격차트, 신선-냉동 대비.
- 난도: 중. 한계: 전국 소매가격에는 산지 어획 신호가 희석될 수 있다. 조석 위상은 항구마다 다르고 명절 수요·주말 조사결측·금어기·날씨를 분리해야 한다. 가격관계가 나오지 않을 가능성도 크다.

#### 5. 채솟값이 뛰면 급식표의 초록색도 줄어들까?
- 데이터 A: KAMIS 일별 채소가격, 위 공식 API의 품목·등급 고정 가격. [KAMIS](https://www.kamis.or.kr/customer/reference/openapi_list.do).
- 데이터 B: NEIS 급식식단정보. 현재년도 학교별·일자별 요리명, 원산지, 칼로리, 영양정보를 CSV/JSON/API로 제공한다. [NEIS 급식식단정보](https://open.neis.go.kr/portal/data/service/selectServicePage.do?infId=OPEN17320190722180924242823&infSeq=1). API 대량호출에는 인증키를 사용한다.
- 연결: 2026년 한 시도 50~100개 학교의 점심 메뉴에서 배추·오이·시금치 등 식재료 이름을 사전으로 추출한다. 식재료 가격 급등 후 0~8주 메뉴 등장률을 비교한다.
- 가설: 식재료 인플레이션은 돈의 변화에 그치지 않고 학생이 접하는 채소의 종류와 대체 식재료를 바꿀 수 있다. 반응이 없다면 장기 공급계약이 가격변동을 흡수하는지라는 반대 메시지도 가능하다.
- 시각화: 채소별 가격선 아래 메뉴등장률 띠, 메뉴 대체 흐름도.
- 난도: 중. 중요 제약: 공식 설명상 현재년도 데이터라 2021~2025년 전체가 API에 남아 있다고 가정하면 안 된다. 메뉴명은 사용량·실제 섭취량이 아니다. 지역 식재료 계약가격과 KAMIS 조사 소매/도매가는 다르다. 방학·학기·메뉴작성 시차 통제.

#### 6. 이른 추석에는 송편 속 밤도 더 비쌀까? (가격자료 재사용 예비안)
- 데이터 A: 한국천문연구원 음양력 정보에서 매년 음력 8월 15일의 양력 날짜를 산출한다. [음양력 정보](https://www.data.go.kr/data/15012679/openapi.do).
- 데이터 B: KAMIS 밤·참깨·쌀 등 관련 품목의 일별/월별 가격과 등급/규격. [KAMIS API](https://www.kamis.or.kr/customer/reference/openapi_list.do). 구체적 밤 품목의 장기 연속기간은 코드표와 실데이터 확인 필요.
- 연결: 10년 이상 연도별 추석 전 2~4주 가격을 같은 해 평시·전년 동기 대비해 '명절 프리미엄'으로 만들고, 추석이 양력으로 이른 해/늦은 해를 비교한다.
- 가설: 같은 명절이어도 수확 달력과 어긋나면 제수음식 재료별로 가격 압박이 다를 수 있다.
- 시각화: 추석 양력 날짜 순으로 정렬한 재료별 가격 달력.
- 난도: 중. 한계: 생산량·저장성·수입·품목등급 변화가 크다. 제철과 수요가 함께 바뀌므로 달력 자체의 인과효과로 단정하지 않는다. 4와 둘 중 하나를 최종 선정 권장.

#### 7. 바다의 보호구역 경계에는 어선이 줄을 설까? (해외)
- 데이터 A: Protected Planet 보호구역 경계. 보호구역 공간정보와 지정 관련 속성의 공식 API가 있다. 2025-11-01 WDPA와 WD-OECM 통합에 따라 명칭·모델 변화가 있어 현재 문서를 사용한다. [공식 API](https://api.protectedplanet.net/), [문서](https://api.protectedplanet.net/documentation/v3). 다운로드/API 이용약관·계정/토큰 확인 필요.
- 데이터 B: Global Fishing Watch apparent fishing effort. AIS를 통해 추정된 조업시간을 격자/구역 단위로 API 또는 다운로드할 수 있다. 2012년 이후 범위를 안내한다. [데이터 안내](https://globalfishingwatch.org/dataset-and-code-fishing-activity/), [API 문서](https://api-doc.globalfishingwatch.org/).
- 연결: 충분한 면적의 금어 보호구역 1~3개를 고르고 2020~2025년 경계 안·밖 1/5/10km에서 면적당 조업시간 비교. 지정 전후도 가능하나 당시 경계이력을 확보해야 한다.
- 가설: 보호구역은 조업을 단순히 없애는 것이 아니라 그 활동을 경계 바깥으로 집중시킬 수 있다.
- 시각화: 경계와의 거리에 따른 조업밀도 곡선, 경계선을 둘러싼 빛나는 띠 지도.
- 난도: 상. 한계: 모든 해양보호구역이 조업금지구역은 아니다. 금지규정·어종·어업별 허용을 먼저 확인하고 불법조업으로 단정하지 않는다. AIS 비송신·소형선 누락, 알고리즘 추정 오차가 있다. API 토큰/계정과 이용량 제한 확인 필요.

#### 8. 다른 나라의 산불이 우리 동네 태양광을 어둡게 만들까? (미국·캐나다)
- 데이터 A: NOAA HMS smoke. 북미의 일별 연기 플룸 영역·시작/종료 시각·농도등급(light/medium/heavy)을 SHP/KML로 제공하고 과거 파일도 있다. [NOAA 공식 HMS](https://ospo.noaa.gov/products/land/hms.html), [2025년 3월 아카이브 예시](https://satepsanone.nesdis.noaa.gov/pub/FIRE/web/HMS/Smoke_Polygons/Shapefile/2025/03/). 별도 인증 없이 공개 아카이브 접근 가능하나 서비스 변경·재처리 공지 확인.
- 데이터 B: 미국 EIA-930. 전력계통 운영구역별 시간별 연료원별 순발전량. 2019-01-01 이후 API/웹 이력, 태양광(SUN) 등 에너지원별 자료는 2018-07-01 이후 수집. [EIA-930 공식 설명](https://www.eia.gov/electricity/930-content/about.html). 무료 API는 키 필요, 웹/파일 다운로드도 제공.
- 연결: 2023년 캐나다 산불 시기 미국 동부 1~3개 계통 운영구역. 하루 연기 피복비중·등급과 낮 시간 태양광발전량 편차를 연결한다.
- 가설: 재난의 영향권은 불이 난 자리보다 넓으며, 먼 곳의 연기가 국경을 넘어 전기 생산에도 흔적을 남길 수 있다.
- 시각화: 연기가 이동하는 지도와 발전량 곡선, 연기 유입 전후 시계열.
- 난도: 상. 한계: 구름·일사량·계절·발전설비 증가·출력제어를 추가 통제하지 않으면 연기의 효과를 구별하기 어렵다. EIA는 대규모 계통 발전 중심이며 주택 지붕 태양광을 모두 포함하지 않으므로 제목의 '우리집 발전량'으로 표현하지 않는다. 시간대 및 서머타임 일치 필요. NOAA 연기 플룸은 지상 미세먼지 농도 측정값이 아니다.

### Inferences
- 최종 20개에서 자료 종류 다양성을 우선하면 꽃축제, 학교급식, 철도-외래식물, 보호구역-어선 등 최소 4개를 선정하기 좋다.
- 가장 독특한 자료수집은 2의 생물사진 시각·좌표 추출이다. 다만 관찰자 편향 때문에 실제 동물행동 연구와 데이터가 만들어지는 방식 자체를 묻는 연구를 분리해야 한다.
- 7과 8은 시각화 결과물이 풍부하고 공개 데이터의 시간·공간 단위도 비교적 명확하나 공간처리 난도가 높다.

### Gaps
- 실제 API 키를 이용한 원자료 수집, 표본 건수·누락률·기간별 가격품목 연속성은 아직 미확인이다.

# 문화와 디지털 흔적의 낯선 연결

## 어떤 조합이 의외이면서 실제 수집 가능한가

### Takeaway
아래 8개는 실제 접근 경로를 확인한 자료를 엮는 아이디어다. 관계나 방향은 아직 분석하지 않은 가설이며, 자료의 존재 확인은 API 실호출 성공이나 완전한 과거 자료 확보를 의미하지 않는다. 우선추천은 1·2·6·8이다.

### Cited Findings

#### 1. 금리가 오르면 사람들은 돈 버는 책보다 마음 달래는 책을 빌릴까?
- 데이터 A: 한국은행 기준금리 추이. 변경 날짜와 금리의 공식 표를 수집하거나 ECOS API 이용. [한국은행 기준금리 변경 이력](https://www.bok.or.kr/portal/singl/baseRate/list.do?dataSeCd=01&menuNo=200643), [ECOS API](https://ecos.bok.or.kr/api/).
- 데이터 B: 정보나루의 기간·연령·KDC별 대출횟수. 재테크·투자 도서군과 명상·철학·마음돌봄 도서군을 서지목록으로 구성한다. 인증키 필요. [정보나루 API](https://www.data4library.kr/apiUtilization).
- 결합: 2016년 이후 월별, 고정 도서관 표본을 가능한 범위에서 유지. 금리 인상 전후 1~3개월과 두 도서군의 대출 비중 비교.
- 가설 메시지: 경제불안이 투자학습뿐 아니라 마음을 돌보는 독서로 옮겨갈 수 있다.
- 시각화·난도: 금리 계단선 아래 두 장르 대출비중 띠그래프 / 중간.
- 주의: 대출은 실제 완독이 아니다. 주가·코로나·베스트셀러 신간·참여도서관 증가를 함께 확인해야 한다. 연령별 API와 고정도서관별 원자료를 동시에 충분히 확보할 수 있는지는 추가 점검 대상이다.

#### 2. 게임이 출시되면 수백 년 전 인물도 다시 유행할까?
- 데이터 A: 역사·신화 게임의 공식 출시일과 등장 배경. 실제로 Assassin’s Creed Odyssey의 스팀 페이지에 출시일 및 고대 그리스 배경이 표시되어 있다. 검은 신화 오공은 서유기를 원작으로 설명한다. [Odyssey](https://store.steampowered.com/app/812140/Assassins_Creed_Odyssey/), [Black Myth Wukong](https://store.steampowered.com/app/2358720/Black_Myth_Wukong/).
- 데이터 B: 위키미디어의 인물·지명·고전 원작 문서별 일별 조회수. [공식 페이지뷰 문서](https://doc.wikimedia.org/generated-data-platform/aqs/analytics-api/reference/page-views.html), [페이지뷰 자료 범위](https://wikitech.wikimedia.org/wiki/Analytics/Data/Pageviews).
- 결합: 2016~2025 출시작 10~20개, 출시 전후 8주, 게임의 직접 등장 인물과 같은 시대의 비등장 인물을 대조. 한국어판 또는 영어판 위키를 구분한다.
- 가설 메시지: 역사에 대한 대중의 관심은 기념일보다 게임 출시일에 더 크게 움직일 수 있다.
- 시각화·난도: 출시일을 0일로 맞춘 여러 인물 조회수 작은 다중그래프 / 중간.
- 주의: 조회는 학습성과가 아니며 영화·논란·마케팅이 함께 작용한다. 문서 언어를 이용자 국적으로 취급하면 안 된다. 출시일 시차 때문에 ±1일 점검 필요. 국제자료 활용 주제다.

#### 3. 외국 드라마를 정주행한 뒤 그 나라 말을 배우기 시작할까?
- 데이터 A: 넷플릭스 한국 주간 Top10의 작품명·주차·순위. 국가별 시청횟수로 오인하지 않고 순위/진입주수만 활용. [넷플릭스 Top10](https://www.netflix.com/tudum/top10/), [국가별 TSV](https://www.netflix.com/tudum/top10/data/all-weeks-countries.tsv), [주간 갱신 공식 안내](https://help.netflix.com/en/node/116472).
- 데이터 B: 일본어·스페인어·태국어 등 언어학습 도서 대출횟수. KDC와 제목으로 학습서를 정한 뒤 주별 집계. 인증키 필요. [정보나루 API](https://www.data4library.kr/apiUtilization).
- 결합: 2021~2025 한국 주간순위와 전국 주별 언어학습 대출. 작품의 원어는 공식 작품정보에서 수작업 보강한다.
- 가설 메시지: 한 나라의 콘텐츠를 보는 일이 그 나라 언어를 배우는 행동으로 이어질 수 있다.
- 시각화·난도: 작품 흥행 주차와 언어별 대출 변화가 이어지는 시차 그래프 / 중간.
- 주의: 한국순위에는 국가별 실제 시청량이 없다. 여행수요·어학시험·방학·해당 언어의 기존 인기가 교란요인이다. 넷플릭스 다운로드 URL은 검색으로 존재 확인했지만 이 조사에서 직접 파일 내용은 내려받지 않았다.

#### 4. 수능은 청소년보다 어른들의 철학책을 더 움직일까?
- 데이터 A: 평가원 수능·모의평가 국어 지문 PDF에서 등장한 철학자·과학자·작가와 시험일을 수작업 코딩한다. [평가원 수능 홈페이지](https://www.suneung.re.kr/).
- 데이터 B: 해당 인물 저서와 해설서의 연령별 대출 추이. 인증키 필요. [정보나루 API](https://www.data4library.kr/apiUtilization).
- 결합: 2016년 이후 가능한 기간의 시험 전후 4주. 10대와 30~50대 증가율을 비교한다.
- 가설 메시지: 시험이 끝난 뒤 지문의 인물을 더 찾아 읽는 집단은 수험생보다 성인일 수 있다.
- 시각화·난도: 인물별·연령별 대출 증가 히트맵 / 중간.
- 주의: 평가원 홈페이지 원문은 열렸으나 이 도구로 기출목록 본문이 읽히지 않아 개별 PDF까지 검증하지 않았다. 출제 직전 EBS 연계교재 효과와 학교 과제를 분리해야 한다. 우선순위 낮은 예비안이다.

#### 5. 전쟁 뉴스에 등장한 나라는 여행서 대신 역사서로 읽히기 시작할까?
- 데이터 A: GDELT의 국가명·분쟁 키워드별 뉴스량 시계열. [공식 DOC API 안내](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/).
- 데이터 B: 그 나라를 다루는 여행서와 역사서의 주별 대출횟수. [정보나루 API](https://www.data4library.kr/apiUtilization).
- 결합: 최근 약 3개월의 한국발 뉴스 또는 한국어 뉴스와 한국 도서관 주별 자료. 장기분석 시 DOC API의 가용기간을 넘으므로 GDELT 원시 아카이브 또는 별도 뉴스 아카이브가 필요하다.
- 가설 메시지: 국제뉴스가 한 나라를 상상하는 방식을 여행지에서 역사·정치의 현장으로 바꿀 수 있다.
- 시각화·난도: 국가별 여행서/역사서 대출비중의 전환 / 중상.
- 주의: 국내 뉴스 공급량은 독자 노출량과 다르다. GDELT 기사 비중은 전수 기사 수가 아니다. 여행 성수기·해외여행제한을 구분해야 한다. 나라별 도서명 수작업 목록이 필요하다.

#### 6. 야구에서 이기면 ‘우리’, 지면 선수 이름이 나올까?
- 데이터 A: KBO 날짜·팀·경기 결과·득실점. 공식 일정 페이지가 경기결과 표 구조를 제공하지만 데이터는 동적으로 불러오므로 별도 수집이 필요하다. [KBO 일정·결과](https://www.koreabaseball.com/Schedule/Schedule.aspx).
- 데이터 B: 구단 공식 유튜브의 경기별 하이라이트·경기후 영상 댓글 텍스트와 작성시각. 공개 댓글 API, 키·호출량 제한 있음. [YouTube 댓글 API](https://developers.google.com/youtube/v3/docs/commentThreads/list).
- 결합: 2024~2025 한 시즌 이상, 동일 구단·동일 영상 유형, 업로드 후 24시간 내 댓글. 경기 날짜·구단으로 수작업 매칭한다.
- 가설 메시지: 승리의 공은 집단으로, 패배의 책임은 개인으로 돌아가는 언어적 흔적이 나타날 수 있다.
- 시각화·난도: 점수차별 ‘우리/선수 실명/감독 실명’ 비중 / 중간.
- 주의: 댓글 작성자가 전체 팬을 대표하지 않고 삭제·모더레이션·업로드 편집 방향에 영향을 받는다. 선수 실명은 칭찬에서도 쓰이므로 감정과 함께 분류해야 한다. 실제 분노나 선수 책임을 단정하지 않는다.

#### 7. 로또 1등 당첨금이 커진 주엔 ‘사직서’를 더 검색할까?
- 데이터 A: 동행복권 회차별 1게임당 1등 당첨금과 당첨게임 수. 현재 페이지의 필드 및 과거 회차 확인 경로를 확인했다. 구형 비공식 JSON API를 전제로 하지 않고 공식 표를 수집한다. [현재 당첨결과](https://m.dhlottery.co.kr/smarPage), [과거 회차 확인 공식 안내](https://www.dhlottery.co.kr/guide/wnrGuide).
- 데이터 B: ‘사직서/퇴사/퇴사하는 법’ 네이버 검색 추이. 날짜·주·월 단위, 연령·성별 선택, 2016년 이후 조회, 앱 등록과 키 발급 필요. [공식 검색트렌드 API](https://developers.naver.com/docs/serviceapi/datalab/search/search.md).
- 결합: 2016~2025 토요일 추첨일을 기준으로 당첨금과 그 다음 주 검색지수. 뉴스에서 강조되는 큰 금액과 단순 당첨금의 차이도 확인한다.
- 가설 메시지: 거액 당첨 뉴스가 실제 퇴사보다 ‘퇴사 상상’에 흔적을 남길 수 있다.
- 시각화·난도: 당첨금 분위별 다음 주 사직서 검색 반응 / 중간.
- 주의: 검색은 퇴사행동이나 당첨자의 검색이 아니다. 월요일·연초·연말·명절·직장 뉴스와 검색량이 겹칠 수 있으며 기대한 관계가 전혀 없을 수 있는 탐색형 주제다. 과거 표를 대량으로 수집하는 기술적 난도는 추가 확인 필요.

#### 8. 대작 게임이 나오는 날, 개발자들의 ‘잔디’는 덜 자랄까?
- 데이터 A: 대작 게임의 공식 출시일과 스토어 공개정보를 수작업 모은다. [게임 출시일 예시](https://store.steampowered.com/app/2358720/Black_Myth_Wukong/).
- 데이터 B: GH Archive의 GitHub 공개 이벤트 원시 JSON 또는 BigQuery. 시간별 아카이브가 있으며 2011년 이후 제공된다. 2015년 이후 동일한 이벤트 수집 체계 구간에서 PushEvent 수를 집계한다. [GH Archive](https://www.gharchive.org/).
- 결합: 2016~2025 여러 출시일 전후 2주, UTC 또는 지역을 명확히 제한한 시간단위 비교. 대작 출시일 1개만 보는 대신 20개 안팎의 이벤트를 모은다.
- 가설 메시지: 여가 콘텐츠의 출시 일정이 업무·창작 플랫폼의 공개 활동에도 잔물결을 만들 수 있다.
- 시각화·난도: 출시일 기준 PushEvent의 평소 요일 대비 변화 / 높음.
- 주의: 공개 푸시만 보며 비공개 업무·실제 노동시간·개인의 게임 이용 여부를 모른다. ‘생산성 감소’로 이름 붙이면 안 된다. 글로벌 총량에서 효과가 작거나 전혀 없을 수 있다. 자동봇 활동, 요일, 공휴일, UTC 시차, GitHub 수집 변경을 통제해야 한다. BigQuery 조회 비용 가능, 파일 직접 다운로드 대안 있음. 국제자료 활용 주제다.

### Inferences
- 정보디자인 과제로는 1·2·6이 주제가 낯설면서도 일상적 설명이 가능하다. 8은 수집방식이 가장 독특하지만 효과가 불분명하고 처리량이 많다.
- 검색·조회·댓글·대출을 각각 실제 퇴사·학습성과·팬 전체 감정·완독으로 바꾸어 해석하지 않아야 한다.

### Gaps
- API 인증키를 발급하거나 실제 데이터를 대량 수집하지 않았으므로 호출 성공, 전체 역사 범위, 자료 결측률은 확인하지 않았다.
- 수능 개별 PDF와 넷플릭스 TSV 내용은 이 조사에서 직접 다운로드하지 않았다. 해당 주제는 자료 확보 단계에서 재점검해야 한다.
- 회차별 로또 과거자료의 현재 대량수집 경로는 추가 확인 대상이다.

#### 중요 보완: 정보나루 과거 대출자료의 단위와 절단표본
- 공식 `loanItemSrch` 설명에는 **조회기간**, 연령, 성별, 지역, KDC 필터와 결과의 **대출횟수**가 명시되어 있다. 예시 요청도 `startDt=2016-01-01&endDt=2016-05-15`이므로 단순 현재 누적치만 제공하는 API는 아니다. 월/주별 기간을 바꾸어 요청하는 설계 자체는 가능하다. 다만 API가 특정 ISBN의 임의 과거 기간 값을 직접 반환한다는 확인은 하지 못했다. [공식 API 설명](https://www.data4library.kr/apiUtilization).
- 공식 인기대출 화면은 월별·연도별 제공방식, 기간설정, KDC·연령 필터를 제공하며 결과건수 선택은 **200·500·1000건**이다. 따라서 '상위200권만'이라는 단정은 틀리지만, **인기순 목록이라는 절단표본**인 점은 분명하다. API 페이지네이션으로 전량을 회수할 수 있는지와 최대 건수는 확인하지 않았다. [공식 인기대출 화면](https://www.data4library.kr/loanDataL).
- `srchDtlList`는 ISBN과 `loaninfoYN=Y`로 대출정보를 제공하나, 요약문서에는 과거 기간 입력이 없으며 `usageAnalysisList`도 ISBN 입력만 제시된다. 도서별 이용분석 웹화면에는 '지난1년/2년 대출추이'가 있으나 차트 원자료와 API 응답필드는 이 조사에서 확인하지 못했다. **임의 ISBN의 2016~2025 주별/월별 전 시계열 및 연령별 교차 시계열을 보장하면 안 된다.** [도서별 이용분석 실제 화면](https://www.data4library.kr/bookV?seq=6864150).
- 따라서 1·3·4·5안의 B를 '분야 전체 대출비중'으로 쓰려면 추가 원자료 확보가 필요하다. 당장 검증 가능한 축소 설계는 **동일 KDC 필터의 월별 상위1000권 목록 중 해당 주제 도서의 수·순위·대출횟수 구성 변화**다. 목록에서 사라진 책을 대출0건으로 간주하면 안 되며 장르 전체 독서수요로 일반화할 수 없다.
- 더 안전한 대안은 B를 네이버 검색어 추이로 교체하는 것이다. 금리안은 '명상/마음챙김' 대 '주식공부/재테크공부', 넷플릭스안은 언어별 '스페인어 공부' 등의 검색, 뉴스안은 국가명과 '역사/여행' 조합이다. 이때는 독서 행동이 아닌 관심 변화라고 명명한다. 네이버는 공식적으로 **2016년 이후·일/주/월·연령/성별 필터**를 지원한다. [공식 네이버 문서](https://developers.naver.com/docs/serviceapi/datalab/search/search.md).

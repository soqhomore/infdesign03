# 사람들이 일하는 이유 조사 자료

수집일: 2026-11-09. 공개 조사 3건에서 응답 항목 16개를 정리했다. 현재 주자료 후보는 한국리서치 2026년 조사이며, 사람인 2011년과 잡코리아 2013년 조사는 과거 보조자료다. 참여자 개인별 자유응답을 수집한 자료가 아니다.

## 파일과 출처

- `survey-items.json`: 조사 방법·기간·표본·질문 요약·문항 위치, 짧은 원문 표현, 응답률, 조사자 분류를 보존한 데이터다.
- [한국리서치 공식 해설](https://hrcopinion.co.kr/archives/37937): 조사 전체 1,000명, 조사기간 2026-07-24~29. 근로 동기 문항은 현재·과거 근로 경험자의 공개 사례수 912를 기준으로 한다. 공식 결과표 C09, 표 c07~c13 및 공식 보고서의 노동 동기 도표를 텍스트로 대조했다. PDF 원문 링크는 JSON에 있다.
- [사람인 원배포 보도자료](https://www.newswire.co.kr/newsRead.php?no=580571): 2011-11-01 발표, 직장인 1,250명, 공개된 근로 동기 6항목. 조사기간·표집·응답 방식과 전체 보기는 미확인이다.
- [잡코리아 원배포 보도자료](https://www.newswire.co.kr/newsRead.php?no=700613): 2013-06-17 발표, 직장인 463명, 공개된 근로 동기 4항목. 조사기간·표집·응답 방식과 전체 보기는 미확인이다.

## 먼저 볼 주자료

별도로 `first-person-quotes.json`에 공개 글 2개에서 확인한 자기 경험 문구 5개를 보존했다. 블라인드의 근로 동기 질문에 대한 직접 답변 3개와, 82cook의 경제활동 경험 서술 2개를 구별했다. 게시일·본문/댓글 위치·짧은 원문을 담았으며, 개인 신원이나 진정성을 검증한 인터뷰는 아니다. 위 설문 16항목과 합산하지 않는다. 현재 게임에 반영하지 않았다.

아래 이름은 조사자 요약이다. 원래 항목 표현은 JSON의 `original_item`에서 확인한다. 비율은 한국리서치의 항목별 긍정 두 단계 합산값이며 서로 배타적인 선택 비율이 아니다.

| 근로 동기 요약 | 동의율 |
| --- | ---: |
| 수입 확보 | 82% |
| 일해야 한다는 의무감 | 61% |
| 생활 리듬 유지 | 46% |
| 대인관계와 소속감 | 41% |
| 적성 발휘와 꿈 실현 | 34% |
| 사회적 기여 | 23% |

정수 반올림 때문에 세부 응답의 합과 공개 합계가 다를 수 있다. JSON의 동의·중립·비동의 값을 100%로 재조정하지 않는다. 전체 표본 1,000명과 이 문항의 사례수 912를 구별한다. 문항 사례수는 공개 가중 결과표 기준이며, 가중 전 문항별 실제 응답자 수를 별도로 확보하지 않았다.

## 작품에서 연결하는 범위

사용자는 사람들의 근로 동기를 물은 데이터를 추가로 수집해 기존 면접 자료와 연결하자고 요청했다. 수집한 주제는 행복버튼 이후 선택지의 근거로 활용할 수 있지만, 아직 런타임 문구나 동작은 변경하지 않았다.

기존 `../model-answers/`는 면접 가이드의 추천 예시다. 면접관을 대상으로 요구를 직접 물은 조사와는 다르다. 일반적으로 일하는 동기와 특정 회사에 지원한 이유 역시 질문이 다르다. 이 두 자료는 주제 비교에 쓰며, 같은 사람이 실제 이유를 숨기거나 거짓말했다는 증거로 연결하지 않는다.

소득뿐 아니라 꿈·소속감·기여도 수집 결과에 포함된다. 이들이 함께 존재할 수 있다는 점을 보존한다. 설문 보기를 1인칭 답변으로 바꿀 때는 편집·창작 문장으로 표시한다. 공개 항목의 비율을 개별 지원자의 속마음이나 합격률로 표시하지 않는다.

## 확보 상태

- 공식 HTML과 PDF는 Firecrawl의 추출 텍스트로 확인했다. PDF 표의 일부 하위집단 열이 흐트러져, 이번 데이터에는 보고서와 일치한 전체행 수치만 넣었다. 원문 시각 검증은 하지 않았다.
- 로컬 네트워크에서 PDF 다운로드가 이름 해석 오류로 실패했다. 원본 PDF·전체 웹페이지·전체 추출문은 이 폴더에 보존하지 않았으며, URL과 필요한 집계값·문항 위치·짧은 표현만 보존했다. 나중에 원본을 확보하면 상태를 갱신한다.
- 과거 보도자료의 공개 항목 합은 사람인 95.2%, 잡코리아 98.6%다. 나머지를 임의의 기타 항목으로 만들지 않았다. 서로 다른 시점·표본·질문 방식의 수치를 합산하거나 변화량으로 해석하지 않는다.
- 사례 16개는 세 조사의 공개 보기 수다. 개인별 답변 16개도, 독립 조사 16건도 아니다.

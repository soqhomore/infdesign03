# 한국어 취업 이유 B 1차 수집

수집일: 2026-11-09. 같은 날짜에 다른 CLI가 작업 중인 기존 문서는 수정하지 않고 이 별도 폴더만 추가했다.

이 폴더의 통합수집.json과 CSV는 동일한 **17행·14개 URL**이다. 직접 취업동기 10행(8개 URL), 보조/반례 7행이다. 직접 동기 중 취준중임을 스스로 명시한 것은 커뮤니티 4행이다. X 직접 동기 4행은 취업 희망이 명확하지만 현재 취준 활동까지 확인하지 못했다. 서로 다른 사람 17명 또는 독립출처 17개라는 뜻이 아니다.

먼저 조사보고서.md를 읽는다. 통합수집.json은 정규화 필드와 원래 레코드를 함께 보존한다. CSV는 비교용이며 동일 자료를 추가 사례로 세지 않는다. research-source-x.json / research-source-social.json은 담당 연구의 원래 구조다. existing-audit.json은 이전 자료의 재검토이며 신규 SNS 행수에 합산하지 않는다. 기존 한국어 X 8건의 취업 조건은 0건이다.

원문 전문이 아니라 출처 페이지별 합계 25단어 이하의 짧은 원문 인용이다. quote 범위와 access_level을 확인한다. X는 Firecrawl 공개 게시물 처리기 반환이며 원 플랫폼 화면과 별도 대조하지 않았다. 커뮤니티는 반환된 본문·댓글을 읽었으나 댓글 영구링크 대신 페이지 URL+표시명을 보존한 경우가 있다. 검색 반환의 제한된 메타데이터는 프로젝트 상위 research_notes/취업 이유와 미뤄둔 생활/에 있다.

SNS와 공개 커뮤니티는 source_type으로 구별한다. 현재 활동자 상태는 게시 당시 본인 진술이지 신원 검증이 아니다. 글 날짜 2013~2026년이 섞였으며 비확률 목적표집이다. ‘모두 거짓말한다’, ‘실제로 면접에서 참았다’, ‘가장 많은 이유’ 등은 이 자료로 증명하지 않는다.

기존 HANDOFF.md와 MANIFEST.json은 이번 추가 파일을 포함하도록 갱신하지 않았다. 기존 인계 ZIP도 과거 시점 그대로다. 최신 B 데이터는 이 폴더를 별도로 읽어야 한다.

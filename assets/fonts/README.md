## 차이 상승체 원본 확보·적용 · 2026-11-10 최신

사용자가 지정한 OTF.zip을 사용자 정보디자인 폴더에서 찾았다. 압축 안 Rising_CHAI_OTF_Light.otf / Rising_CHAI_OTF_Extra_Bold.otf의 내부 한글 이름이 차이 상승체임을 확인했다. 원본 ZIP은 references/fonts/OTF.zip, 런타임 원본 OTF 두 파일은 assets/fonts/에 내용 변경 없이 보존했다. 제목은 800 Extra Bold, 발언 블록·크레딧·생활 엔딩 대사는 300 Light다. 본문·버튼·입력은 Pretendard, 행복버튼 이후 면접 대사와 저격은 Bithumb Original을 유지한다. 아래의 차이 상승체 미확보 설명은 이 파일을 찾기 전 상태다. interface.css는 scripts/build-interface-fonts.mjs로 재생성하며 npm run build:fonts에 포함했다. native Canvas에서 두 OTF 로드와 한글 측정을 확인했다. 실제 브라우저 외관은 미검증이다.

PretendardVariable.woff2는 사용자 로컬 Pretendard 1.3.9 패키지에서 복사했다. SIL OFL 전문은 Pretendard-LICENSE.txt. interface.css는 같은 바이너리를 data URL로 포함해 이전 실행 서버의 MIME 설정에도 의존하지 않는다. 차이 상승체 바이너리는 현재 미확보이며 CSS display 폰트에 이름만 지정하고 Pretendard로 대체한다. 차이 상승체가 실제 적용됐다고 주장하지 않는다. 행복버튼 이후 면접 대사/저격은 Bithumb Original을 유지한다.

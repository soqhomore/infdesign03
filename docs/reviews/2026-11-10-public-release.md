# 공개 점검 해제와 Vercel 연결

사용자의 최신 승인에 따라 점검 화면을 현재 3D 면접 여정으로 교체했다. 이전의 점검 유지 지침을 대체한다.

- 공개 첫 화면과 `/interview.html`: 현재 3D 면접 여정. 생성 원본은 `local/room.html`이다.
- 공개 대화: 기존 준비 대사 모델을 공유하는 브라우저 메모리 엔진. 두 번 답변 → 행복버튼 → 실제 다음 답변부터 발끈 → 네 번 반박 → 엔딩과 크레딧을 유지한다.
- 공개 버전은 AI를 사용하지 않는다는 안내가 있다. 입력 답변은 서버/AI로 보내지 않는다. 브라우저 음성 인식은 해당 서비스로 전송될 수 있다는 기존 안내를 유지한다.
- 로컬 `/local/`: 기존 Node API와 AI 모드 유지. 공개 AI 공급자·키·과금 구성을 이번 변경에서 새로 만들지 않았다. 공개 준비 대사 방식은 작업 중 명시한 구현 선택이다.

기존 서버를 그대로 Vercel에 올리는 방식은 로컬 호스트 제한과 메모리 세션 의존을 해결하지 못한다. 이번 공개 체험은 새 서버 없이 안정적으로 진행되는 구성을 우선했다.

`npm run build`는 공개 진입점을 생성하고 `dist`에 실행 파일만 복사한다. `.env`, 서버 소스, 기획 문서, 수집 원본, node_modules는 포함하지 않는다. assets의 기존 실행용 발췌·폰트 라이선스·음향 크레딧은 포함된다. 정적 배포의 `/local/`도 공개 체험을 연다. 로컬 서버의 `/local/`과 구분한다.

Vercel 설정은 [공식 vercel.json 문서](https://vercel.com/docs/project-configuration/vercel-json)의 buildCommand, outputDirectory, framework:null 구성을 사용한다. 프로젝트 대시보드 설정을 바꾸지 않고 저장소 설정으로 빌드 경로를 고정했다.

검증: build, 구문 검사, 테스트 112개와 기존 lifecycle smoke 3시나리오 통과. 공개 엔진과 Node 준비 대사의 대화 결과 일치, 실제 클라이언트의 서버 요청 없는 진행, 중복 요청·만료·취소·입력 제한, 공개 파일과 비공개 자료 제외, 빌드 출력 경로 보호를 검사했다. 앱 JS의 상대/절대/Three import 경로가 산출물에서 모두 해소됨을 확인했다. 독립 읽기 전용 리뷰 완료.

한계: 도구 실행 환경에서 GitHub DNS와 브라우저 호스트가 연결되지 않는다. 실제 원격 푸시·Vercel 빌드·WebGL/음성은 성공으로 주장하지 않는다. GitHub 업데이트 뒤 Vercel 배포 결과를 별도로 확인해야 한다.

Ruling: 글자 블록은 접근 가능한 DOM 버튼과 CSS 부유로 구현하고 문밖 공간·문·생활 소품은 실제 Three.js로 유지한다. 읽기/키보드 접근성을 보존하기 위해 원문을 캔버스 이미지로만 만들지 않는다.
Ruling: 기존 생활 엔딩 데모 모듈은 테스트와 자산 호환을 위해 보존하며 본 체험은 새 여정 컨트롤러를 사용한다.
Ruling: 일반 소득/비교/취준 종료 발언은 생활 안정 장면에 기본 연결하되 입장 전 장면을 바꿀 수 있다. 수정 문장은 별도 AI 재작성을 하지 않는다.

리뷰 수정: 시작 실패를 문밖에도 표시, 생활 타이머 일시정지, 이전 음성 인식의 늦은 종료 이벤트 무시. 회귀 테스트 포함.

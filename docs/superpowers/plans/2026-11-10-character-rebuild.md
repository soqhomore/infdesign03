# 면접관 자산 교체 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 왼쪽 의상 렌더링 오류를 수정하고 가운데 한 명을 공식 인체·정장 자산 기반으로 교체한다.
**Architecture:** 기존 공간·대화·얼굴 교체 인터페이스를 유지한다. 공식 CC0 의상/인체 데이터를 로컬 빌드 과정에서 착석 자세로 변형해 런타임용 자산으로 저장한다. 사진은 얼굴 앞면에만 제한하고 의상에는 투영하지 않는다.
**Tech Stack:** 기존 Three.js, Node/Python 자산 변환. 외부 유료 모델 생성 없음.
**Spec:** 사용자가 승인한 '버그 수정 → 가운데 한 명을 완성된 인체/의상 자산으로 재구성 → 정면·옆모습·반응·사진 교체 확인 → 나머지 적용' 제안. 나머지 두 명은 이번에 오류만 고친다.

## Global Constraints

- 공개 점검 페이지 유지. 푸시·배포하지 않는다.
- 기존 방·카메라·조작·다회 대화를 유지한다.
- 원본 시안의 인상은 참고하되 동일한 개인 두상 복원이라고 주장하지 않는다.
- 사용자가 고른 사진은 로컬 처리한다.
- 미추적 b-social 자료 등 다른 작업은 수정하지 않는다.

## Review Focus

- 음수 좌표가 GLSL 연산자로 합쳐지지 않음.
- 실제 의상 메시의 어깨·팔꿈치·목과 피부가 잘 연결됨.
- 얼굴 투영이 귀·옆머리의 사진 배경을 드러내지 않음.
- 자산 출처·라이선스·원본과 파생 데이터를 구별함.
- 실제 GPU 결과가 미확인인 경우 구문/CPU 검증과 구별함.

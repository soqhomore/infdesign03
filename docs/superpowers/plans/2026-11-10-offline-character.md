# 로컬 인체 기반 면접관 재구성 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 추가 다운로드 없이 기존 CC0 전체 인체 메시에서 가운데 면접관의 착석 몸체와 의상을 제작한다.
**Architecture:** 원본의 인체 토폴로지와 관절 표식을 활용해 빌드 단계에서 착석 변형을 적용한다. 동일한 인체 표면에서 의상과 노출 피부를 나눠 연결을 유지하고, 런타임에는 파생 지오메트리를 로드한다. 가운데 의상은 사진 투영을 쓰지 않는다.
**Tech Stack:** 기존 Node/Three.js 및 CC0 hm08 원본. 새 패키지·다운로드 없음.
**Spec:** 사용자가 승인한 '기존 전체 인체를 착석시키고 체형에 맞는 재킷·셔츠 제작, 얼굴 경계 정리, 한 명부터 확인' 대안.

## Global Constraints

- 공개 점검 화면 유지, 로컬 작업만. 기존 방·카메라·조작·사진 교체·대화 유지.
- 가운데 한 명만 새 몸체를 적용한다. 나머지는 이전 렌더링 오류 수정 상태 유지.
- 이 결과는 직접 제작한 의상이며 완성형 의상 자산을 다운로드했다고 주장하지 않는다.
- 사용자 사진은 로컬 처리하며 공통 두상을 개인별로 복원하는 기능은 아니다.
- unrelated b-social 자료를 수정하지 않는다.

## Review Focus

- 손·팔·몸통이 같은 원본 표면으로 연결되고, 관절 변형 뒤 과도한 늘어짐·뒤집힘이 없음.
- 재킷·셔츠·바지·피부가 겹쳐 반짝이거나 비어 보이지 않음.
- 기본 시점과 옆 시점의 형상 확인을 구문 테스트와 구분.
- 얼굴 교체/복원과 면접 반응 자세가 새 몸체에도 적용됨.
- 삼각형·그리기 호출·파일 크기 증가를 측정함.

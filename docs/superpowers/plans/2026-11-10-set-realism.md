# 대기실·침실 사실감 보강 기록

완료: 기존 로컬 목재 PBR 재사용, 페인트/천 미세 표면, 둥근 모서리, 문 부속과 의자, 침구와 키보드 소품, 스포트 그림자, 공유 환경광·SSAO 후처리, 비 장면 30fps 제한.

Ruling: 새 후처리 컴포저·외부 에셋 없이 기존 면접실 체인을 빌려 쓰고 finally로 복원한다. PMREM 소유권은 원 면접실에 둔다.

리뷰 수정: 최초 면접실 보기에도 shadowMap.needsUpdate를 세워 그림자 맵을 생성한다.

검증: 전체 76개 통과, 마지막 침구 정리 후 관련 6개 통과. Chrome 실행 오류로 실제 외관/성능 미검증.

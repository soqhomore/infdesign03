# 대기실 입장 실행 기록

완료: 큰 패널 축소 / 화면 전체 대기실 / 한 문장 수정 / 단일 확인 버튼 / 호명 전 정적과 호흡 / 직접 문 열기 / 착석 후 첫 질문 / 설정 및 자료 분리 / 초기 종료 보호 / 기존 엔딩·행복버튼 유지.

Ruling: 호명은 기기 TTS+자막, 분위기 소리는 합성으로 구현해 새 파일 다운로드와 AI 호출을 추가하지 않는다. 실제 기기 음량은 별도 확인이 필요하다.

검증: 전체 72개 통과. 독립 리뷰 후 버튼 DOM 조상 숨김 회귀 및 세션 없는 종료 회귀 테스트 추가. 브라우저는 Chrome 실행 오류로 미검증.

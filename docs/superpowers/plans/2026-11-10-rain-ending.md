# 비 오는 침실 구현 기록

사용자 방향: bed.jpeg의 국소 조명과 어두운 방, 비와 빗소리로 우울한 결말. 참조 이미지를 열어 확인했다.

Ruling: 기존 다섯 공간 대신 공통 침실+바람별 소품을 추천하고 비동기 질문했다. 응답 미수신 상태에서 합리적 대기 후 추천 기본값을 알리고 진행했다.

완료: 실제 3D 방·침구/소품, 절차적 창밖 비·물방울, 빗소리 합성, 14초 체류와 대사 여백, 크레딧 8초 음향 페이드, 일시정지/음소거/초기화.

리뷰: 중복 자원 해제/음향 상태/RectAreaLight 초기화 확인. 역순 smoothstep 수정. 실제 WebGL·기기 음량 미검증.
